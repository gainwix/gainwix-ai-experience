## How to roll back

Cloud Run keeps every previous revision. Rolling back = pointing traffic at the
previous revision (no rebuild needed).

```bash
# See revisions
gcloud run revisions list --service <name> --region <region> --project <project>

# Send 100% of traffic back to a known-good revision
gcloud run services update-traffic <name> \
  --region <region> --project <project> \
  --to-revisions <REVISION>=100
```

## How to scale

```bash
gcloud run services update <name> \
  --region <region> --project <project> \
  --min-instances <N> --max-instances <N> --concurrency <N> \
  --cpu <N> --memory <Mi>
```

- **Scale to zero:** set `--min-instances 0` (cheapest; cold starts on first hit).
- **Always warm:** set `--min-instances 1+`.
